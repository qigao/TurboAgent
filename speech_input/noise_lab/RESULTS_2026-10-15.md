# SpeexDSP 1.2.1 NS-only: independently observed evidence (2026-10-15)

**Experimental Draft PR #163. NOT production ANC, VAD, ASR, SDK or release.**

This is actual SpeexDSP native C library code at 16kHz/320 S16 samples,
not a simulated noise reducer. Library: Ubuntu 24.04 dev package
`libspeexdsp-dev 1.2.1-1ubuntu3` with `pkg-config speexdsp=1.2.1`;
recorded installed shared binary
`/usr/lib/x86_64-linux-gnu/libspeexdsp.so.1.5.2` SHA-256
`ef4e0d1c80fb4fcf832bb98be7df08b44faaed84ee2c003070fa1b1023a1c5fd`.
This exact package/SO fingerprint is Linux runner-specific, not a portable
installed SDK or complete dependency source sanitizer acceptance.

Source license: [Xiph SpeexDSP COPYING](https://github.com/xiph/speexdsp/blob/SpeexDSP-1.2.1/COPYING),
BSD-3-Clause. No vendor sources or copyrighted model weights were copied
into the TurboAgent tree. The separate C11 NS-only adapter is strictly bounded
at 3,000 input frames and disabled by default.

Results **after experimental one-frame drain+alignment**:

| Input | NS setting | Output/input energy | Best-offset cosine similarity | Original nonzero 20ms frames becoming zero after alignment | Guard after NS |
|---|---|---:|---:|---:|---|
| Generated stationary noise | -12 dB | 0.272736 | 0.840710 | 0/200 | dynamic_or_unknown |
| Generated stationary noise | -18 dB | 0.239185 | 0.742106 | 0/200 | dynamic_or_unknown |
| Original genuine whisper | -12 dB | 0.976090 | 0.999662 | 1/111 | dynamic_or_unknown |
| Original genuine whisper | -18 dB | 0.976100 | 0.999647 | 5/111 | dynamic_or_unknown |
| Actual road warning noise | -12 dB | 0.608115 | 0.898574 | 0/375 | dynamic_or_unknown |
| Actual road warning noise | -18 dB | 0.592563 | 0.860151 | 1/375 | dynamic_or_unknown |

**Do not mistake any of these for WER/CER, SNR, listener intelligibility,
acoustic VAD quality or hallucination rejection.** Cosine similarity is
waveform alignment correlation, not speech content. A real whispered word has
111 original nonzero frames; 1 versus 5 aligned nonzero frames become
digital zero after filtering at -12/-18 respectively. Even though both
settings keep ~97.6% total audio energy, weak consonants may be attenuated.
Neither setting is authorized as a production default.

The traditional SpeexDSP overlap processing emitted output one full
20ms frame later for these fixtures. Without explicit draining, the first
output was a priming frame and the final 320 samples of speech had **not**
been emitted. The experimental C11 `finish` API drives one zero frame,
seals the Owner, and allows a private diagnostic to discard the primer and
append the delayed tail. **This is not yet verified end-to-end with device
Capture timestamps, cancellation before drain, hardware clock drift or
Owner/DSO unload races.**

## Release-blocking next gates

1. Real nonstationary/ambient noise and natural low-volume/monotone voice
   corpora, multiple speakers, true near/far SNR, Japanese/Chinese whisper,
   code-switching. Long quiet words and weak consonants need actual phonetic
   evidence, not only broad power ratios.
2. Explicit consent/approval for pinned Whisper weights to compare original,
   NS -12 and NS -18 on *same* clips for CER/WER, hallucination, speech dropout,
   CPU, memory and added latency. No model download in this diagnostic.
3. Full-source dependency Sanitizers and exact native release binary pins
   for Linux/macOS/Windows/Android/iOS, not only Linux distro source adapter
   instrumentation. Explicit ABI and installed SDK ownership if integration
   is eventually authorized.
4. Lifecycle tests for 20ms first-frame latency, one-shot tail drain,
   cancel-first, no second Owner, no raw persistence, final VAD decision
   independent of NS return, and safe DSO teardown.

**Recommendation now:** retain this as a test-only Linux native NS candidate.
If a next experimental configuration must be ranked without actual ASR
quality evidence, -12 dB is the *more conservative* of the two tested
noise-suppression settings on this single real whispered sample; this is
not a production quality recommendation. Keep all #137/#146 PRs Draft,
`stationary_noise_guard` default OFF and NS absent from production.
